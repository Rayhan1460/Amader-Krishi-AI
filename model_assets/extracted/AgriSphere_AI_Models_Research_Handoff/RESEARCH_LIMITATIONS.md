# Research limitations

- **Tomato Disease Detection:** Validation-selected experimental checkpoint; PlantDoc macro F1 about 0.440; independent field test REQUIRED.
- **Rice Disease Detection:** Seven classes; reported accuracy 0.574, macro F1 0.548; split not verified field-independent.
- **Crop Recommendation:** Public 22-crop benchmark with macro F1 0.993; NOT validated advice for Bangladesh farmland.
- **Crop Yield Prediction:** Regional historical research; MAE 0.260 source units; target physical units NOT independently verified; NOT farm-level.
- **Flood Susceptibility (Disaster sub-task):** Station-held-out AP 0.716 F1 0.702; static historical flood susceptibility, NOT real-time prediction/cyclone alert.
- **Market Price — Tomato:** Weekly WHOLESALE BDT/kg research; model MAE 9.6159 > last-price baseline MAE 5.8448; prefer baseline.
- **Market Price — Boro Rice:** Weekly WHOLESALE BDT/kg research; model MAE 0.7534 > last-price baseline MAE 0.7372; prefer baseline.
